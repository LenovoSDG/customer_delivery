# 语音识别开发对比

2026-11-25，Apple Silicon Mac；同一段16 kHz单声道合成语音先经浏览器 Vosk small-cn-0.22，再由本机 Whisper large-v3-turbo Q4 核准。语音由 macOS Tingting / Meijia 以225字/分钟生成；未采集用户现场音频。

这只是4段合成音频的开发回归，不能代表真实用户口音、设备或噪声环境下的准确率，也不能作为泛化性能结论。

## 结果

忽略标点，以原文字母和数字为基准计算字符编辑距离（替换、删除、插入）。116个基准字符中，Vosk字符错误数为7（CER 6.03%），Whisper为2（CER 1.72%）。

### 01-greeting.wav（Tingting）

- 原文：各位客户评审专家，大家好。我是本次项目交付的负责人。
- Vosk：各位客户评审专家大家好我是本次项目交付的负责人
- Whisper：各位客户评审专家,大家好,我是本次项目交付的负责人。
- 字符编辑距离：0 → 0

### 02-terms.wav（Meijia）

- 原文：我们采用本地化部署、权限分级和操作审计，保障客户数据安全。
- Vosk：我们采用本地化部署权限分级和操作审计保证客户数据安全
- Whisper：我们采用本地化部署全线分级和操作审计保障客户数据安全
- 字符编辑距离：1 → 2

### 03-metrics.wav（Tingting）

- 原文：跨部门协作时长按任务创建到最终验收的时间差统计，并排除撤回和测试数据。
- Vosk：跨部门协作时常看任务创建到最终验收的时间差统计并排除撤回和测试数据
- Whisper：跨部门协作时长按任务创建到最终验收的时间差统计,并排除撤回和测试数据。
- 字符编辑距离：2 → 0

### 04-guides.wav（Meijia）

- 原文：凌云办公协同升级项目的管理员操作手册和员工快速上手指南，将在周五前提供。
- Vosk：明明办公系统升级项目的管理员操作手册和员工快速上手指南将在周五前提供
- Whisper：凌云办公协同升级项目的管理员操作手册和员工快速上手指南，将在周五前提供。
- 字符编辑距离：4 → 0

## 已知边界

“权限分级”在Meijia样本中被Whisper识别成“全线分级”，该样本的错误数反而略有增加，说明仍有同音词错误。没有使用语言模型编造或补全用户发言。项目术语只作为ASR词汇提示。

最终提交教练的是Whisper根据原始PCM音频得到的结果，不是Vosk实时预览；界面在停顿后修正预览。音频只送至127.0.0.1上的本机识别服务，不发往玻尔模型网关，不落盘。核准失败时不把错误预览悄悄当最终发言发送。

## 来源与复现

- [Whisper large-v3-turbo 原模型](https://huggingface.co/openai/whisper-large-v3-turbo)
- [本项目使用的MLX Q4权重](https://huggingface.co/mlx-community/whisper-large-v3-turbo-q4)，固定revision `660c343bbf4e52ac257f0b7d952e5388e6f93bef`，下载时检查SHA-256。
- `npm run setup:voice-hq` 安装识别引擎与权重，`npm start` 运行。对比数据由开发测试页面读取相同语音并观察核准前后文字得到；产品中的音频导入入口已移除。开发对比数据存于未提交的 `outputs/asr-comparison/`。
- 自动化测试覆盖默认自动朗读、完整反馈朗读、连续两轮不重新申请麦克风、朗读回声隔离、取消后过期识别结果忽略，以及PCM输入校验。
